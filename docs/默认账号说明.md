## 2. 角色权限说明

### ADMIN
管理员拥有系统全部权限，包括但不限于：

- 登录系统
- 查看个人信息
- 修改密码
- 查看和管理线索
- 删除客户
- 查看和维护跟进记录
- 查看和更新任务
- 使用 AI 助手
- 查看报表
- 管理团队成员
- 管理渠道预算
- 管理机器人规则

### MANAGER
经理拥有业务管理权限，包括：

- 登录系统
- 查看个人信息
- 修改密码
- 查看和管理线索
- 删除客户
- 查看和维护跟进记录
- 查看和更新任务
- 使用 AI 助手
- 查看报表
- 查看/更新渠道预算
- 查看/更新机器人规则

### USER
普通用户拥有基础业务权限，包括：

- 登录系统
- 查看个人信息
- 修改密码
- 查看和编辑线索
- 查看和新增跟进记录
- 查看和更新任务
- 使用 AI 助手

普通用户默认**无权访问**以下功能：

- 渠道预算设置
- 机器人规则配置
- 报表页
- 删除客户

## 4. 安全提醒

### 开发/测试环境
可以保留默认账号，方便快速联调。

### 演示环境
如果对外演示，建议至少修改管理员密码，避免误操作。

### 生产环境
上线前必须完成以下事项：

- 修改所有默认密码；
- 禁用演示账号或改为正式账号；
- 使用加密密码（BCrypt）存储；
- 修改 JWT 密钥；
- 仅保留必要账号；
- 严格配置角色权限。

## 5. 常见问题

### 1）为什么登录失败？
请检查：

- 账号是否输入正确；
- 密码是否已被修改；
- 数据库初始化是否成功；
- 后端是否已正确启动。

### 2）为什么登录成功但看不到某些菜单？
这是正常现象。系统会根据角色控制菜单和接口权限：

- `ADMIN` 可见全部菜单；
- `MANAGER` 可见部分管理菜单；
- `USER` 仅可见基础业务菜单。

### 3）修改密码后为什么旧密码不能再登录？
因为系统已将新密码写入数据库，旧密码会失效。  
如需恢复演示账号，可重新执行初始化逻辑或重置数据库种子数据。
