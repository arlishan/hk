# LeadBot 部署操作手册

本文档用于说明 `LeadBot` 项目的部署方式，覆盖以下场景：

- Windows 本地部署
- Linux 服务器部署
- Docker Compose 部署

同时包含：

- 前端构建方式
- 后端打包与启动方式
- MySQL 数据库准备
- Nginx 反向代理配置
- 生产环境注意事项
- 常见故障排查

---

# 1. 项目组成

LeadBot 项目由以下部分组成：

- 前端：`leadbot-vue`
  - Vue 3 + Vite
  - 构建后输出 `dist/`
- 后端：`leadbot-backend`
  - Spring Boot 3
  - 打包后输出 Jar
- 数据库：
  - MySQL 8
- 反向代理：
  - Nginx（推荐）
- 容器化部署：
  - Docker Compose（可选）

---

# 2. 端口约定

建议统一使用以下端口：

- 前端访问端口：`80`
- 后端服务端口：`8080`
- MySQL 端口：`3306`

# 3. 部署前准备

## 3.1 环境要求

### 前端环境
- Node.js 18+
- npm 9+

### 后端环境
- JDK 17
- Maven 3.8+

### 数据库环境
- MySQL 8.0+

---

## 3.2 数据库准备

先创建数据库：

```sql
CREATE DATABASE IF NOT EXISTS leadbot
DEFAULT CHARACTER SET utf8mb4
DEFAULT COLLATE utf8mb4_general_ci;
```

如果项目启用了 Flyway，则后端首次启动时会自动建表和迁移。  
如果没有启用 Flyway，可手动执行：

- `database/sql/01_schema.sql`
- `database/sql/02_seed.sql`

# 4. Windows 本地部署

适用于：

- 本地开发联调
- 交付演示
- 内网测试

---

## 4.1 启动后端

进入后端目录：

```bash
cd leadbot-backend
mvn clean package -DskipTests
java -jar target\leadbot-backend-1.2.0.jar
```

如果要指定生产环境配置：

### CMD
```bat
set SPRING_PROFILES_ACTIVE=prod
java -jar target\leadbot-backend-1.2.0.jar
```

### PowerShell
```powershell
$env:SPRING_PROFILES_ACTIVE="prod"
java -jar .\target\leadbot-backend-1.2.0.jar
```

后端默认访问地址：

```text
http://localhost:8080
```

Swagger 地址：

```text
http://localhost:8080/swagger-ui.html
```

---

## 4.2 前端环境变量配置

前端开发环境 `.env.development` 推荐配置：

```env
VITE_API_MODE=real
VITE_API_BASE_URL=http://localhost:8080
VITE_APP_TITLE=LeadBot Dev
```

如果只是本地运行并直接请求后端，保持上述配置即可。

---

## 4.3 构建前端

进入前端目录：

```bash
cd leadbot-vue
npm install
npm run build
```

构建产物目录：

```text
leadbot-vue/dist
```

---

## 4.4 本地预览前端

可直接执行：

```bash
npm run preview
```

默认会启动一个本地预览服务。

---

## 4.5 Windows 推荐辅助脚本

### 启动后端 `start-backend.bat`

```bat
@echo off
set SPRING_PROFILES_ACTIVE=prod

```

建议将生产配置放在：

```text

```

示例：

```yml

  datasource:
    url: jdbc:mysql://127.0.0.1:3306/leadbot?useSSL=false&serverTimezone=Asia/Shanghai&characterEncoding=utf8
    username: root
    password: 123456

  jpa:
    hibernate:
      ddl-auto: validate
    show-sql: false

  flyway:
    enabled: true

server:
  port: 8080
```

---

## 5.5 后端启动命令

```bash
SPRING_PROFILES_ACTIVE=prod java -jar /opt/leadbot/backend/leadbot-backend.jar --spring.config.location=/opt/leadbot/backend/config/application-prod.yml
```

---

## 5.6 使用 systemd 管理后端服务（推荐）

创建：

```text
/etc/systemd/system/leadbot.service
```

内容如下：

```ini
[Unit]
Description=LeadBot Backend
After=network.target

[Service]
User=root
WorkingDirectory=/opt/leadbot/backend
Environment=SPRING_PROFILES_ACTIVE=prod
ExecStart=/usr/bin/java -jar /opt/leadbot/backend/leadbot-backend.jar --spring.config.location=/opt/leadbot/backend/config/application-prod.yml
SuccessExitStatus=143
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

执行：

```bash
sudo systemctl daemon-reload
sudo systemctl enable leadbot
sudo systemctl start leadbot
sudo systemctl status leadbot
```

查看日志：

```bash
journalctl -u leadbot -f
```

## 5.8 Nginx 配置

配置文件建议放：

```text
/opt/leadbot/nginx/leadbot.conf
```

示例：

```nginx
server {
    listen 80;
    server_name your-domain.com;

    root /opt/leadbot/frontend/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:8080/;
        proxy_http_version 1.1;

        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /swagger-ui/ {
        proxy_pass http://127.0.0.1:8080/swagger-ui/;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
    }

    location /v3/api-docs/ {
        proxy_pass http://127.0.0.1:8080/v3/api-docs/;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
    }
}
```

启用配置：

```bash
sudo ln -s /opt/leadbot/nginx/leadbot.conf /etc/nginx/sites-enabled/leadbot.conf
sudo nginx -t
sudo systemctl reload nginx
```

# 6. Docker Compose 部署

适用于：

- 标准化测试环境
- 快速一键拉起
- 前后端和数据库统一容器化

---

## 6.1 后端 Dockerfile

在 `leadbot-backend/` 下创建：

```dockerfile
FROM eclipse-temurin:17-jre

WORKDIR /app
COPY target/leadbot-backend-1.2.0.jar app.jar

EXPOSE 8080

ENV SPRING_PROFILES_ACTIVE=prod

ENTRYPOINT ["java", "-jar", "app.jar"]
```

---

## 6.2 前端 Dockerfile

在 `leadbot-vue/` 下创建：

```dockerfile
FROM node:20-alpine AS build

WORKDIR /app
COPY . .
RUN npm install
RUN npm run build

FROM nginx:stable-alpine
COPY --from=build /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf

EXPOSE 80

CMD ["nginx", "-g", "daemon off;"]
```

---

## 6.3 前端容器内 Nginx 配置

在 `leadbot-vue/nginx.conf`：

```nginx
server {
    listen 80;
    server_name localhost;

    root /usr/share/nginx/html;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://backend:8080/;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

---

## 6.4 Docker Compose 文件

```yaml
version: '3.9'

services:
  mysql:
    image: mysql:8.0
    container_name: leadbot-mysql
    restart: always
    environment:
      MYSQL_ROOT_PASSWORD: 123456
      MYSQL_DATABASE: leadbot
    ports:
      - "3306:3306"
    volumes:
      - ./mysql-data:/var/lib/mysql

  backend:
    build:
      context: ./leadbot-backend
    container_name: leadbot-backend
    restart: always
    depends_on:
      - mysql
    environment:
      SPRING_PROFILES_ACTIVE: prod
      SPRING_DATASOURCE_URL: jdbc:mysql://mysql:3306/leadbot?useSSL=false&serverTimezone=Asia/Shanghai&characterEncoding=utf8
      SPRING_DATASOURCE_USERNAME: root
      SPRING_DATASOURCE_PASSWORD: 123456
    ports:
      - "8080:8080"

  frontend:
    build:
      context: ./leadbot-vue
    container_name: leadbot-frontend
    restart: always
    depends_on:
      - backend
    ports:
      - "80:80"
```

# 8. 推荐发布流程

---

## 8.1 手动发布

### 前端
```bash
cd leadbot-vue
npm install
npm run build
```

把 `dist/` 上传到：

```text
/opt/leadbot/frontend/dist/
```

### 后端
```bash
cd leadbot-backend
mvn clean package -DskipTests
```

上传 jar 到：

```text
/opt/leadbot/backend/leadbot-backend.jar
```

然后重启服务。

---

## 8.2 脚本发布（推荐）

### `deploy-frontend.sh`

```bash
#!/bin/bash
cd /opt/source/leadbot-vue || exit
npm install
npm run build
rm -rf /opt/leadbot/frontend/dist/*
cp -r dist/* /opt/leadbot/frontend/dist/
echo "frontend deployed"
```

### `deploy-backend.sh`

```bash
#!/bin/bash
cd /opt/source/leadbot-backend || exit
mvn clean package -DskipTests
cp target/leadbot-backend-1.2.0.jar /opt/leadbot/backend/leadbot-backend.jar
systemctl restart leadbot
systemctl status leadbot --no-pager
echo "backend deployed"
```

# 12. 常见问题排查

## 12.1 登录失败
检查：
- 用户初始化是否成功
- 后端密码是否 BCrypt 正确
- 接口返回是否正常

## 12.2 401 未授权
检查：
- 前端是否带了 `Authorization: Bearer token`
- 后端 JWT secret 是否一致
- token 是否过期

## 12.3 403 无权限
检查：
- 当前账号角色
- 后端角色配置
- 前端权限菜单显示逻辑

## 12.4 前端空白 / 请求失败
检查：
- `.env.production` 是否正确
- `VITE_API_BASE_URL` 是否匹配 Nginx 代理
- 浏览器 Network 面板查看实际请求地址

## 12.5 Flyway 执行失败
检查：
- 旧表结构是否和迁移脚本冲突
- 是否混用了 `ddl-auto=update`
- 是否有旧数据残留
