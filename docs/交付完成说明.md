## 4. 还需要你在本地执行的步骤

由于部分运行产物必须通过你本地环境构建生成，所以在最终交付前，还需要你执行以下动作。

---

### 4.1 前端安装依赖并构建

进入前端源码目录：

```bash
cd shj.py\leadbot-h5\frontend\source\leadbot-vue
npm install
npm run build
```

如果你想本地预览构建结果：

```bash
npm run preview
```

### 构建完成后
会生成：

```text
dist/
```

你可以将其复制到：

```text
shj.py\leadbot-h5\frontend\dist
```

---

### 4.2 后端打包生成 Jar

进入后端源码目录：

```bash
cd shj.py\leadbot-h5\backend\source\leadbot-backend
mvn clean package -DskipTests
```

构建成功后会生成类似：

```text
target/leadbot-backend-1.2.0.jar
```

你可以将其复制到：

```text
shj.py\leadbot-h5\backend\jar\
```

建议最终命名为：

```text
leadbot-backend-1.2.0.jar
```

---

### 4.3 数据库初始化验证

在 MySQL 中依次执行：

1. `database/sql/01_schema.sql`
2. `database/sql/02_seed.sql`

验证内容包括：

- 库是否创建成功
- 表是否创建成功
- 默认账号是否可登录
- 线索、任务、成员、渠道、规则数据是否正常

---

### 4.4 前后端联调验证

建议联调顺序：

1. 启动后端
2. 启动前端
3. 登录系统
4. 打开工作台
5. 测试线索分页 / 搜索 / 筛选
6. 测试线索新建 / 编辑 / 删除
7. 测试跟进记录查看 / 新增
8. 测试任务更新
9. 测试 AI 聊天
10. 测试角色权限控制
11. 测试修改密码
12. 测试报表页、团队页、渠道页、规则页
