# LeadBot 接口说明

## 1. 文档概述

本文档用于说明 LeadBot 智能获客系统后端接口的整体规范、认证方式、主要业务接口及响应结构，方便前后端联调、接口测试和后续系统扩展。

当前系统主要覆盖以下业务模块：

- 认证模块
- 用户信息模块
- 线索管理模块
- 跟进记录模块
- 任务管理模块
- AI 聊天模块
- 团队成员模块
- 渠道设置模块
- 规则设置模块

---

## 2. 基础信息

### 2.1 服务地址

开发环境示例：

```text
http://localhost:8080
```

生产环境示例：

```text
https://your-domain.com
```

### 2.2 接口风格

- 协议：HTTP / HTTPS
- 数据格式：JSON
- 字符编码：UTF-8
- 风格：RESTful

### 2.3 请求头

除登录接口外，其他受保护接口通常需要携带认证信息：

```http
Content-Type: application/json
Authorization: Bearer <token>
Accept: application/json
```

## 3. 统一返回格式

### 3.1 成功响应

```json
{
  "code": 0,
  "message": "ok",
  "success": true,
  "data": {}
}
```

### 3.2 失败响应

```json
{
  "code": 401,
  "message": "未登录或登录已过期",
  "success": false
}
```

### 3.3 字段说明

| 字段 | 类型 | 说明 |
|---|---|---|
| code | number | 业务状态码，`0` 表示成功 |
| message | string | 响应消息 |
| success | boolean | 是否成功 |
| data | any | 业务数据 |

---

## 4. 认证机制

系统采用 JWT Token 方式进行鉴权。

### 4.1 登录流程

1. 调用登录接口提交账号密码
2. 服务端验证成功后返回 token
3. 前端保存 token
4. 后续请求通过 `Authorization: Bearer <token>` 传递

### 4.2 认证失效

当 token 失效、过期或未传递时，接口可能返回：

- HTTP 状态码：`401`
- 业务码：`401`
- 响应消息：`未登录或登录已过期`

## 5. 角色权限说明

系统当前设计了三类角色：

### 5.1 ADMIN
- 全部权限
- 团队成员管理
- 渠道设置
- 规则配置
- 报表查看
- 线索管理
- 删除客户

### 5.2 MANAGER
- 线索管理
- 跟进记录
- 任务管理
- AI 聊天
- 数据报表
- 渠道管理
- 规则管理
- 删除客户

### 5.3 USER
- 线索查看与编辑
- 跟进记录
- 任务管理
- AI 聊天
- 个人资料
- 无法访问团队成员、渠道、规则、报表管理类接口

## 6. 分页约定

部分列表接口支持分页。

### 6.1 通用分页参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| page | number | 否 | 页码，从 1 开始 |
| pageSize | number | 否 | 每页数量 |

### 6.2 通用分页响应结构

```json
{
  "code": 0,
  "message": "ok",
  "success": true,
  "data": {
    "list": [],
    "total": 100,
    "page": 1,
    "pageSize": 10
  }
}
```

## 8. 认证模块

### 8.1 登录

**请求方式：**
`POST /auth/login`

**请求参数：**

```json
{
  "username": "admin",
  "password": "123456"
}
```

**响应示例：**

```json
{
  "code": 0,
  "message": "ok",
  "success": true,
  "data": {
    "token": "jwt-token",
    "user": {
      "id": 1,
      "name": "系统管理员",
      "role": "ADMIN",
      "avatar": "A"
    }
  }
}
```

---

### 8.2 获取当前用户信息

**请求方式：**
`GET /auth/profile`

**请求头：**
需要 `Authorization`

**响应示例：**

```json

  "code": 0,
  "message": "ok",
  "success": true,
  "data": {
    "id": 1,
    "name": "系统管理员",
    "role": "ADMIN",
    "avatar": "A"
```

## 9. 线索管理模块

### 9.1 获取线索列表

**请求方式：**
`GET /leads`

**支持参数：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| keyword | string | 否 | 客户姓名/公司关键字 |
| level | string | 否 | 客户等级：`high/follow/new` |
| page | number | 否 | 页码 |
| pageSize | number | 否 | 每页数量 |

**请求示例：**

```text
GET /leads?keyword=教育&level=high&page=1&pageSize=10
```

**响应示例：**

```json
{
  "code": 0,
  "message": "ok",
  "success": true,
  "data": {
    "list": [
      {
        "id": 1,
        "name": "张晓峰",
        "company": "启航教育",
        "industry": "教育培训",
        "phone": "138****2234",
        "level": "high",
        "status": "待跟进",
        "source": "抖音投流",
        "tags": ["高意向", "校区扩张", "已回复"],
        "note": "建议24小时内完成二次跟进",
        "lastFollow": "今天 10:20"
      }
    ],
    "total": 1,
    "page": 1,
    "pageSize": 10
  }
}
```
